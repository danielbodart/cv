Recent Technical Work (2025-2026)

Agent Safety Stack

Lets Claude Code and Codex run on NixOS with real tools but no credentials, no root and no unmediated egress. The agent is treated as untrusted; every approval moves to a host daemon that decides by policy or asks a person. Zig, Go, Nix. 685 commits, 340+ releases in 6 weeks.

  • flong: ephemeral rootless containers from NixOS config — ~10ms start vs Docker's ~120ms. No capabilities, 4-filter seccomp stack proven byte-for-byte stricter than systemd-nspawn's
  • frisket: kernel-steered (TPROXY) egress proxy. The sandbox holds a placeholder; the real token is swapped in on the wire (intercepts HTTPS and SSH), with allow/ask/refuse per request
  • chase: picks a sandbox tier by unforgeable checkout path. 5,400+ API operations classified read/write/guarded; per-project grants signed by a TPM key
  • quoin: TPM-backed SSH agent (hardware-level signing; keys never leave the chip) and a sudo gate written as a Zig sudo plugin — an agent's git push or sudo waits for a human, even across machines via ssh -A
  • galley: zenity drop-in that stacks approvals from parallel agent sessions into one queue
mogwai-db — Graph Database & Agent Memory

TinkerPop 4 graph database with SQLite as its engine. One graph = one SQLite database, running in the browser, at the edge, on bare metal or in Docker. TypeScript, Bun. 2,500 commits, 300+ releases in 4 months.

  • Compiles each whole Gremlin traversal into one SQL statement — no step-by-step interpreter. ~82% of the official TinkerPop conformance suite via the unmodified client, ratcheted in CI
  • Four runtimes from one core: SQLite WASM on OPFS, Cloudflare Durable Objects (scale to zero), single binaries for 5 OS/arch targets, Docker
  • Query plans fixed at compile time: 1-hop lookup 9.8s → 19ms without statistics. FTS, graph algorithms, federation and CouchDB-style replication, all in SQL
  • Direction — agent memory: physically isolated per-agent graphs that cost nothing idle, queried via a language and code sandbox next to the data rather than a bag of tools
  • Built through parallel Claude Code agent workflows behind an 8-level test ladder
Nix Fleet — Reproducible, Rollback-able, Agent-Safe Machines

Every machine in the house in one flake: NixOS desktop, laptop and server, nix-darwin Mac, OpenWrt router and 4 access points, and a Raspberry Pi. 10 hosts, one rebuild command. 548 commits in 8 weeks.

  • Secure Boot (lanzaboote), LUKS sealed to the TPM, SSH and secrets keys that never leave the TPM
  • Claude Code and its MCP servers pinned as Nix packages with read-only config. The agent safety stack is wired in fleet-wide, and any bad change is one reboot from rollback
  • Offline bare-metal reinstall from one encrypted USB key; home server upgrades itself hourly from trunk, waiting until nobody is playing
  • nix-raspios-imagebuilder (locked Pi OS images, A/B upgrades with auto-fallback) and claude-desktop flake
Game Server Fleet

Self-hosted Minecraft Bedrock, Valheim and Hytale servers for me and my kids, run as hands-off infrastructure. Game updates flow in automatically and never interrupt anyone mid-game. Every tool runs on Docker or natively on systemd, with NixOS modules. Go, Docker, Nix.

  • Chandlery: game servers as Docker images built from scratch (the image tag is the game version) or as confined systemd/NixOS services from the same image. Graceful stop, real health checks and a console either way
  • Tidewaiter: an auto-updater that waits until no one is playing, detecting players by watching live connections (UDP too). Swaps in a new version only once it's healthy, and rolls back otherwise. Covers Docker and NixOS services
  • Treesinger: Hytale sign-in broker. Sign in once and every server shares the login through short-lived sessions; in Docker or socket-activated under systemd
  • Portical UPnP port forwarding from a single Docker label or systemd key
Capsper — Voice Dictation & Meeting Transcription

Fully local voice dictation and meeting transcription for Linux and macOS. Hold CapsLock, speak, release — text appears in any focused window. Zig. 250+ releases.

  • Single Zig binary: keyboard interception (evdev/CGEventTap), audio capture (PipeWire/CoreAudio), mel spectrogram, ONNX/CoreML inference, SentencePiece detokenisation, keystroke injection
  • NVIDIA Nemotron Speech 600M (FastConformer RNNT) — inherently incremental streaming ASR
  • CPU-only on Linux by measurement: ~8x realtime. 28x CPU cut (28 → 1.4 cores) by fixing ONNX Runtime threads that never idled
  • Meeting capture: virtual PipeWire sink, WebRTC echo cancellation (12.6 dB), stereo Opus + WebVTT with speakers labelled by construction

Spin-off projects:

  • nemotron-speech-600m-onnx — ONNX export with 4 precision variants (FP32/FP16/INT8 dynamic/INT8 static). Static INT8 required warm-cache streaming calibration to avoid blank-token collapse
  • nemotron-speech-600m-coreml — CoreML conversion: 93% Apple Neural Engine utilisation, ~15.5x realtime. 3-level numerical validation
  • ten-vad-ggml — ONNX→GGML converter + complete Zig inference implementation of TEN-VAD. LSTM gate reordering. Verified <0.001 delta vs native
  • fulcio-codesign — Fulcio/Sigstore code signing with TCC permission persistence across binary updates
